## 1.11.1 TLS与实际联网修复

2026-10-22复现：受影响的打包运行时在SSLContext初始化时需要辅助PEM策略文件；缺失时直接抛出FileNotFoundError，因此所有HTTPS来源同时失败。修复采用构建钩子按需原样收集运行时文件，不修改信任策略、不跳过证书及主机名验证；标准Python环境无需这份文件。

新增5项测试，总计84项本地测试通过。构建后使用发行EXE执行离线TLS检查，验证SSLContext可创建、hostname_check=true、verify_mode=CERT_REQUIRED；这一步纳入build.ps1，构建缺失资源时失败。原有单纯GUI启动检查不足以发现本次问题，已补上此验证。

发行EXE的真实联网检查成功：Bangumi简介/评分及封面已读取；Nyaa RSS返回75条，蜜柑100条、DMHY 500条，AnimeGarden探测查询1条。上述为本轮只读诊断的来源响应数量，不代表任何动画的全部资源覆盖率，也不代表下载器任务验收。

诊断命令：

```powershell
.\AniFerry-1.11.1.exe --tls-check --data-dir .\tls-check
.\AniFerry-1.11.1.exe --network-check BANGUMI_ID --data-dir .\network-check
```

联网诊断需把BANGUMI_ID替换为待检查的动画条目数字ID，并使用单独输出目录；不提交下载任务。诊断输出留在本机，不应公开个人库或缓存。
