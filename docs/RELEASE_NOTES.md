# 番舟 AniFerry 1.11.1

修复介绍和资源连接失败，并同步搜索及界面更新。

## 本次修复

- 修复某些打包运行时缺少TLS辅助数据，导致全部HTTPS请求报“找不到文件”的问题；保留证书和主机名验证。
- 构建时增加发行程序的离线TLS检查，避免只通过界面启动检查就发布。
- 介绍与封面遇到临时网络错误会重试一次。

## 从1.10.0升级可获得

- 修复分割季度带Part 2等后缀导致漏检总标题资源的问题，使用分集资料确认范围后补搜。
- 支持续作/分割放送按需开启本季与全篇双集数，默认关闭，不改写历史编号。
- 简化主界面：检查所选、全部候选、追踪设置分层进入；来源状态、诊断和说明放到工具菜单。
- 候选展开、补充别名、排除词、查询级增量显示，以及来源限速和失败退避。

## 下载与升级

Windows x64用户解压完整 `AniFerry-1.11.1-Windows-x64.zip`，关闭旧版后启动 `AniFerry-1.11.1.exe`，保留同目录 `_internal/`。已有追番和下载记录沿用原数据目录。

本地84项回归测试、打包TLS检查及GUI启动检查通过；发行程序实际读取Bangumi介绍/封面及四个资源来源成功。来源可用性仍受网络和站点收录影响；新增下载器的完整下载流程验收边界见验证说明。
