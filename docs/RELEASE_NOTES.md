# 番舟 AniFerry 1.10.0

番舟是一款面向Windows本地追番整理的桌面工具：查找新番资源、浏览作品资料，核对后把种子交给下载器。项目由“追番信箱”更名而来，继续使用原数据目录。

## 主要功能

- Nyaa四名称检索，结合AnimeGarden、蜜柑和動漫花園补充资源，按infohash去重，优先推荐ANI。
- Bangumi封面、简介、评分与评分分布；首次、每日启动及5小时详情间隔缓存策略。
- BitComet、qBittorrent、aria2、Motrix 1.x和迅雷转交适配；哈希与目录核对后确认接收。
- 独立集数范围、完成后旧集弃置、批量删除/忽略及当前动画待核对清理。
- 六套主题、柔和圆角卡片，以及已修正的按钮居中与资源表对齐。
- 无中文/未知字幕资源导出后续工作流队列；不内置AI字幕生成。

## 安装与适用范围

使用Windows x64，解压完整 `AniFerry-1.10.0-Windows-x64.zip` 后运行同目录EXE；无需另装Python，但下载器需自行安装和配置。新用户先在设置中修改下载目录。默认目录沿用旧版的 `E:\动画\202610\追番`。

关闭旧版后运行新版，追番数据仍在 `%LOCALAPPDATA%\AnimeTracker`。适合个人本地追番和下载器转交，不包含播放器、云端下载服务或后台Windows服务；确认资源前请核对作品、季度及集数，并仅处理有权获取的内容。

## 验证与当前限制

55项本地回归测试、独立源码目录复测以及Windows打包与空配置启动检查通过。qBittorrent/aria2/Motrix目前主要通过本地HTTP模拟服务验证协议；BitComet、迅雷读取本机任务记录曾验证，四种新增下载方式尚无新任务完整下载验收。迅雷还需在新建任务窗口确认下载目录。只下部分文件不会自动认定整集完成。
