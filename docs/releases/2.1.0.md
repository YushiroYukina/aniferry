# 番舟 AniFerry 2.1.0 更新说明

本次以2.0.0为比较基线，集中改进缺集找回、资源纠正、转交状态与数据恢复。保留已有追番方式，新增操作放入二级窗口和右键菜单。

## 集数记录与定向补搜

动画资源区新增“集数管理”。按集查看完成与转交记录；即使第6集已完成，也不会把缺失的第3集视为完成。默认列出本地记录范围，可填写截止集查看尚无记录的集数。

选中集数后可单独补搜，包含已退出日常嗅探范围的旧集。结果进入“补搜候选”，仍由用户确认后转交；不修改日常检索下限，不自动恢复用户明确忽略的资源。可结束补搜，完成对应集数后也会移除该补搜目标。双集数开启时沿用原有编号换算。

## 作品订阅源与误匹配纠正

追踪设置新增“作品订阅源”，每部最多绑定4个支持来源的公开RSS：Nyaa、蜜柑作品/搜索、動漫花園。订阅与原有检索同时工作，仍核对片名、季度和集数，并非绑定后无条件收录。

候选右键可标记“不是本作”“季度不符”“集数识别错误”。纠正只针对当前作品与对应资源，不自动生成可能误伤其他资源的全局规则。原有一键批量忽略继续保留；工具菜单可查看并恢复忽略、纠正和清理记录，恢复后仍执行正常筛选。

## 任务状态与谨慎重试

“任务与转交记录”统一展示任务状态、下载器、保存目录与最近核对时间。支持读取的下载器会补充暂停、排队、检查中及下载异常状态；连接异常和目录不符单独显示。状态来自最近检查，不能作为实时速度或所有下载器均支持的保证。

待接收超过2分钟，并且成功检查仍未发现任务时，显示“长时间未接收”。只有下载器可连接、且最近60秒内确认没有对应任务，才允许恢复待选；再次转交仍先检查已有哈希与目录。程序不会自动删除、暂停或重建下载器任务。

## 备份恢复与列表迁移

首次升级2.1时自动备份数据库；工具菜单提供手动备份和恢复，恢复前检查完整性并再次备份当前数据，完成后重新启动程序。数据库备份包含本机设置及加密凭据，请妥善保管。

分享或迁移作品清单可使用列表导入导出：只携带作品名称、关联条目和允许的追踪偏好，不含下载器凭据、任务历史、订阅地址或视频。导入前校验全部条目，已有作品跳过。

## 使用与升级

Windows x64，下载器需另行安装配置。解压完整包，关闭旧版后运行 `AniFerry-2.1.0.exe`。保留 `_internal` 目录，数据继续使用原本的 `AnimeTracker` 用户目录。旧版安装包可保留；需要回退时优先使用升级前备份，不同时运行新旧版本。

本版本不包含播放器、AI字幕生成、托盘运行、云同步或全自动下载。字幕标记仍依据资源标题。搜索覆盖受来源、命名、分页和网络情况影响，不承诺每个作品都能找到全部资源。

本地验证范围见[验证说明](../VALIDATION.md)。源码与发布准备包不含个人追番库、下载器配置和实际资源文件。旧版2.0说明保留在[历史说明](2.0.0.md)。
