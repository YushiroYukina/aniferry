# 番舟 AniFerry 2.0.0 · 主版本更新

番舟2.0现已发布。本次将资源检索、追踪管理与界面优化整合为独立主版本，提供新的安装包和发布页。此前1.x版本及附件继续保留，默认下载入口改为2.0。

## 更新重点

### 更可靠的资源检索

修复分割放送条目带有“Part 2 / 第2部分”等后缀时，无法找到沿用总标题资源的问题。程序会先核对Bangumi分集范围，再进行补充搜索，减少漏检和跨季度误匹配。

完善多语言名称、繁简写法及部分罗马音变体匹配；支持补充别名、排除词、来源分页和ANI优先推荐。查询返回后逐步显示候选，同一来源加入限速与连续失败退避。

### 更清爽的主界面

主界面保留检查所选、推荐资源、转交和忽略等常用操作。全部候选、追踪设置进入独立二级窗口，来源状态、详细诊断、使用说明和活动记录集中放入工具菜单。

“检查所选”可只刷新当前选中的一部或多部动画；“全部候选”可展开推荐外的有效资源，查看匹配依据，再选择转交或批量忽略。后台刷新时保留已选中的候选。

### 按需开启的双集数

续作及分割放送可在追踪设置中开启“本季 / 全篇”双集数，例如“本季第3集 / 全篇第15集”。支持资源编号方式与筛选范围换算，默认关闭，已有下载记录继续沿用。

### 修复介绍与资源连接失败

补齐特定打包环境缺少的TLS辅助资源，修复介绍、封面与资源检索同时连接失败的问题。新增打包后的TLS初始化检查，并保留证书和主机名验证。介绍和封面遇到临时网络错误时会重试一次。

### 保留原有追番能力

继续支持Bangumi作品资料、独立集数范围、完成后旧集弃置、批量整理、六套配色，以及BitComet、qBittorrent、aria2、Motrix 1.x和迅雷转交适配。

## 适用与验证

适用于Windows x64及本地下载器追番整理，下载器需要自行安装配置。资源由用户确认后转交，字幕标记根据标题判断。

84项回归测试、发行包TLS与启动检查纳入验证。新版本继承已修复并实测通过的Bangumi介绍/封面及四个资源来源连接能力；来源可用性和完整下载器验收范围见[验证说明](https://github.com/YushiroYukina/aniferry/blob/main/docs/VALIDATION.md)。
